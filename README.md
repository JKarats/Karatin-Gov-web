# Government Contracting Website — GitHub Pages

## Files
- `index.html` — website content
- `styles.css` — website design
- `script.js` — mobile menu and automatic copyright year
- `capability-statement.pdf` — add your real capability statement using this exact filename

## Customize before publishing
Open `index.html` in a text editor and replace:

- `Your Company Name`
- `YOUR COMPANY`
- `Add UEI`
- `Add CAGE`
- NAICS codes
- Business certifications
- Email address
- Phone number
- City and state
- Services and differentiators

## Add the contact form
1. Create a free account at Formspree.
2. Create a form.
3. Copy your form endpoint.
4. Replace:
   `https://formspree.io/f/your-form-id`

## Publish with GitHub Pages
1. Sign in to GitHub.
2. Click **New repository**.
3. Name it something like `company-website`.
4. Set it to **Public**.
5. Upload `index.html`, `styles.css`, `script.js`, and your capability statement.
6. Open **Settings** → **Pages**.
7. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
8. Click **Save**.

Your website will appear at:

`https://YOUR-GITHUB-USERNAME.github.io/company-website/`

## Optional custom domain
You can later connect a domain such as `yourcompany.com` from the GitHub Pages settings.
